# Security Policy

## ⚠️ CRITICAL: No Secrets
**NEVER commit API keys, tokens, or passwords to this repository.**
* This is a public repository.
* Use \`.env\` files (which are \`.gitignore\`'d) for local secrets.
* If you accidentally commit a secret, consider it compromised immediately. Rotate the key.

## Reporting a Vulnerability
If you discover a security issue (e.g., unsafe permissions in a script, exposed paths), please do **not** open a public issue.
* Email: [Your Email Here]
* Or open a generic issue asking for a private channel.

## Supported Versions
We only support the latest version of this repository. Older commits are considered deprecated and unsupported.
